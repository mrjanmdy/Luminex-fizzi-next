
# 🥤 Fizzi Website

A **3D animated e-commerce landing page** for the fictional soda brand **Fizzi**, built with **Next.js**, **React Three Fiber**, **GSAP**, and **Prismic CMS**.  
This project demonstrates modern frontend development with animations, 3D graphics, and a headless CMS integration.



## 🚀 Features

- ⚡ **Next.js 14** with App Router support  
- 🎨 **Tailwind CSS** for styling and utility-first design  
- 🌀 **GSAP** for smooth animations  
- 🌌 **React Three Fiber** + **drei** for 3D scenes  
- 🧩 **Prismic CMS** with Slice Machine for content modeling  
- 🔄 **Zustand** for lightweight state management  
- ✅ ESLint + Prettier + Tailwind Prettier plugin for clean code  
- 📦 TypeScript for type safety
